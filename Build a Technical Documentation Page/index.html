Printing Text

The print() function displays output on the screen.

You can print text in quotes or numbers and expressions.

print("Hello, World!") # prints text print(5 + 3) # prints result of calculation
  • print() shows output on the screen
  • Can print text in quotes or numbers/expressions
Variables and Operators

Variables store values that you can use and modify in your program.

Operators perform mathematical operations on values.

      
x = 10    # assignment
y = 5

# Arithmetic operators
print(x + y)  # addition → 15
print(x - y)  # subtraction → 5
print(x * y)  # multiplication → 50
print(x / y)  # division → 2.0
print(x % y)  # modulus → remainder → 0
print(x ** 2) # exponent → 100
  • = assigns value to variable
  • + - * / % ** are basic math operations
If Statement

The if statement is used for decision making and conditional execution.

It checks a condition and runs code depending on whether it is True or False.

      
age = 16
if age >= 18:
    print("You can vote")
else:
    print("You cannot vote")
  • if → checks a condition
  • else → runs if condition is False
While Loop

A while loop repeats a block of code as long as a condition is True.

The loop stops when the condition becomes False.

      
i = 1
while i <= 5:
    print(i)
    i = i + 1
  • Prints numbers 1 to 5
  • while keeps running until the condition is False
For Loop

A for loop iterates over a sequence of values.

The range() function generates numbers from start to end-1.

      
for i in range(1, 6):
    print(i)
  • Prints numbers 1 to 5
  • range(start, end) generates numbers from start to end-1
